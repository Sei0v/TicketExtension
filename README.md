
## How to Download
1. Press the green **Code** arrow.
2. Click on **Download ZIP**.
3. Extract the downloaded file (UnZIP).

## Usage
1. Open your browser and go to **Manage extensions**.
   * Links: `brave://extensions/` or `chrome://extensions/`
2. Turn on **Developer mode** (usually in the top right corner).
3. Click on **Load unpacked**.
4. Select the extracted folder, and you are ready to go!
